Blokları ile kullanılır. Eğer if bloğu içindeki koşul sağlanıyorsa if bloğu çalışır, sağlanmıyorsa else bloğu çalışır. blockların içine yazılabilir {% if islem == 1 %}

1. işlem seçildi

{% elif islem == 2 %}

2. işlem seçildi

{% else %}

1 ve 2 dışında bir işlem seçildi

{% endif %} Listeler için ise kullanılır. Yine blokların içerisine yazılabilir. İtem ise python blouğna yazılır. Bu bir demette olabilir, bir liste olabilir, bir sözlük olabilir.
    {% for item in liste %}
  • {{ item }}
    • {% endfor %}
